# Deliver through evidence-gated stages

Implementation proceeds sequentially through legacy-input removal, pure Android 17 vendor import, minimal standalone build, secure relocatable Web distribution, native launcher/authenticated capture, reproducible release engineering, full compatibility/performance/security validation, and protected candidate/final publication. Each stage has an explicit evidence-based exit gate and preserves small commits separating pure upstream content, one class of adaptation, and its behavior-locking tests, preventing downstream complexity from masking a broken standalone foundation.
